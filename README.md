# ✈️ Projeto Viagens dos Sonhos

> **Status do Projeto:** Concluído ✅

Projeto colaborativo desenvolvido como atividade prática para o domínio de tecnologias Web (HTML5, CSS3) e controle de versão com Git/GitHub. O objetivo foi criar um portal de turismo imersivo com múltiplos destinos internacionais.

---

## 👥 Integrantes e Responsabilidades

Cada integrante foi responsável pela curadoria de conteúdo, estruturação técnica e estilização de um destino específico:

* **Davi Moreira:** 🏔️ Suíça (Zermatt)
* **Higor Torres:** 🇵🇹 Portugal (Lisboa)
* **Italo Pereira Gomes:** 🏝️ Maldivas (Atóis)
* **Breno:** 🇩🇪 Alemanha (Baviera)

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando as melhores práticas de desenvolvimento front-end:

* **HTML5:** Estruturação semântica.
* **CSS:** Estilização avançada, uso de Flexbox, Grid e efeitos de *Glassmorphism*.
* **Font Awesome:** Ícones vetoriais.
* **Google Fonts:** Tipografia moderna (Poppins).
* **Git & GitHub:** Controle de versionamento e colaboração.
* **GitHub Pages:** Hospedagem e deploy do projeto.
